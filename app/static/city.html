PLANNING WORKFLOW

From scenario to dispatch.

  1. Place a depot and delivery locations. All vehicles start and return at that depot.
  2. Set capacity and delivery requirements. Automatic allocation assigns deliveries; manual allocation preserves the selected vehicles.
  3. Compare routes and review each vehicle's load. Remote destinations use reachable collection points; original locations stay visible.

Quantum comparison uses the original two-vehicle model. Larger scenarios use classical planning; heuristic results are not certified global optima.

Map and road services receive scenario coordinates. Travel estimates exclude live traffic.
